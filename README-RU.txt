GoshaCrash — минимальная локальная установка для ASUS RT-AC68U
================================================================

Что это
-------
Этот каталог собирает готовую папку для флешки. На роутере ничего
не скачивается. Используется только config.yaml.

Что сохраняется из рабочего проекта
------------------------------------
- Mihomo ARMv5 с тегом with_gvisor;
- TUN-интерфейс tun0;
- проверенная маршрутизация через mark 0x2333 и table 2022;
- DNS: клиенты -> dnsmasq:53 -> Mihomo:1053;
- Zashboard на порту 9090;
- автозапуск ASUSWRT и Download Master;
- восстановление правил после перезапуска firewall.

Сборка в WSL
------------
1. Открой терминал в этом каталоге.
2. Выполни:

   chmod +x BUILD_USB.sh
   ./BUILD_USB.sh

Готовая папка появится здесь:

   dist/GoshaCrash-USB

Также будет создан архив:

   dist/GoshaCrash-USB.tar.gz

Установка
---------
1. Скопируй папку GoshaCrash-USB целиком в корень флешки.
2. Вставь флешку в роутер. Download Master должен быть установлен.
3. Подключись к роутеру:

   ssh admin@10.10.10.100

4. Посмотри имя флешки:

   ls /tmp/mnt

5. Запусти установку, подставив имя флешки:

   cd /tmp/mnt/ИМЯ_ФЛЕШКИ/GoshaCrash-USB
   sh install.sh

Проверка
--------

   ./goshacrash status
   ./goshacrash doctor

Панель:

   http://10.10.10.100:9090/ui/

Пароль API покажет команда status.

Важно
-----
Шаблон config.example.yaml специально запускается в безопасном режиме DIRECT.
Он проверяет Mihomo, gVisor, TUN, DNS, маршрутизацию и автозапуск, но сам по себе
не содержит личных VPN-серверов. Для реального VPN замени config.yaml своим
конфигом, сохранив обязательные параметры TUN/DNS из шаблона, затем выполни:

   ./goshacrash restart

Меню
----

   ./goshacrash

1 — перезапустить
2 — обновить всё из папки GoshaCrash-update в корне флешки
0 — выход
