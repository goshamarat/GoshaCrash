# GoshaCrash 3.10.2-rc10

Critical fix for USB resume/stale geometry detection.

BusyBox fdisk output on RT-AC68U:
  /dev/sda1  1  14959  120158136  83  Linux

Field 4 = Blocks.
Field 5 = partition Id (83).

rc8/rc9 incorrectly parsed field 5 as fdisk_blocks, producing fdisk_blocks=83
and forcing a false stale-geometry result every time.

rc10 uses field 4 consistently in all fdisk geometry comparisons.
