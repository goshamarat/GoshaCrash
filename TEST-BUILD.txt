# GoshaCrash 3.10.2-rc9

Fixes rc8 resume detection on 32-bit BusyBox ash.

Root cause:
disk_blocks * 98 overflowed 32-bit shell arithmetic for the 123 GB USB disk.

Fix:
convert block counts to MiB first, then calculate the 98% threshold.

Added Resume check diagnostics showing:
part count, MBR type, fdisk blocks, kernel blocks.
