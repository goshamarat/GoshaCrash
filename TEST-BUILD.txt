# GoshaCrash 3.10.2-rc11

Fixes package bootstrap on RT-AC68U EXT3.

Observed rc10 failure:
  sh: can't resolve symbol '__aeabi_uidivmod'

Root cause:
ipkg was forced through an Optware LD_LIBRARY_PATH overlay. Child firmware
/bin/sh and wget inherited ancient Optware uClibc and failed.

rc11:
- prefers ipkg with LD_LIBRARY_PATH unset;
- uses the selected clean runtime for ipkg update/install/remove;
- keeps ABI overlay only as compatibility fallback;
- fixes USB filesystem detection that incorrectly returned rootfs for
  /tmp/mnt/SANDISK.
