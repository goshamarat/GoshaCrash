# GoshaCrash 3.10.2-rc12

Fixes after successful rc11 end-to-end installation on RT-AC68U:

1. Installer unsets inherited LD_LIBRARY_PATH at startup.
   Manual `unset LD_LIBRARY_PATH` is no longer required before install.
2. USB filesystem detection now selects the longest containing mountpoint.
   /tmp/mnt/SANDISK correctly resolves to ext3 instead of tmpfs/rootfs.
3. Legacy ARMv5 policy is documented as manual routing only + gVisor.
4. Clean Optware runtime from rc11 is preserved.
