# GoshaCrash 3.10.2-rc6

Primary test path:
Rufus -> Non bootable -> MBR -> Large FAT32 -> one full-size partition
-> ASUS -> sh /tmp/install.sh --prepare-usb -> EXT3.

Safety change:
A single /dev/sdX1 is reused only if it occupies >=98% of the physical USB disk.
A small/partial single partition is NOT silently formatted and left wasting the
rest of the drive.

No fdisk/reboot is expected for the normal Rufus layout.
