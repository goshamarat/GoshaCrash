# GoshaCrash 3.10.2-rc8

Fix: resume after old ASUSWRT BLKRRPART/stale-geometry reboot.

Resume is accepted only when:
- exactly one /dev/sdX1 exists;
- partition type is 83 (Linux);
- it occupies >=98% of the physical disk;
- fdisk block count equals /proc/partitions block count.

Then fdisk is skipped and installer continues directly to:
mkfs.ext3 -L SANDISK /dev/sdX1

This prevents the rc7 loop.
