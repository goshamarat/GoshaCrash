# GoshaCrash 3.10.2-rc21

BT10 package-path fixes are now based on commands verified manually on the real router.

Confirmed manually before this build:
- /dev/sda1 bind-mounted on /opt gives a writable full Optware root;
- /opt/libexec, /opt/man/man1 and /opt/var can be created on USB;
- plain ipkg reinstall then creates /opt/libexec/sftp-server successfully;
- Optware-NG ncurses-base 5.7-7 can be unpacked with:
    ipkg -o <staging-root> -force-depends install <ipk>
- that staging payload contains x/xterm, x/xterm-256color and v/vt100;
- copying only staging opt/share/terminfo to real /opt/share/terminfo makes nano open normally with TERM=xterm-256color.

rc21 changes:
- creates conventional top-level Optware dirs before package work;
- uses the exact proven offline ipkg command (no -force-defaults);
- never uses BusyBox find -type/-path in terminfo checks;
- checks exact compiled terminfo files directly;
- leaves ASUS ncurses-base 5.7-8 installed and copies only architecture-neutral terminfo data;
- runtime recreates the same writable /opt layout after reboot;
- gc doctor checks terminfo data directly instead of executing incompatible infocmp.

Legacy RT-AC68U path remains unchanged when /opt already writes through to Download Master.
