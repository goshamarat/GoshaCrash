# GoshaCrash 3.10.2-rc13

Modern/BT10 portability hardening:
- modern core install no longer hard-depends on legacy Optware package payload;
- firmware unzip/gzip/wget/curl are sufficient;
- nano/SFTP/package manager optional on modern;
- NVRAM USB hooks are now actually installed;
- old ipkg USB bridge only when appropriate;
- auto-detect-interface enabled only when nft exists;
- wget uses private writable HOME to avoid HSTS-store noise;
- BT10 detection logs uname architecture and selected Mihomo target.

RT-AC68U legacy policy remains ARMv5 + gVisor + manual routing only.
