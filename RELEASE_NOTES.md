# GoshaCrash 3.0.0-online

- Один сетевой `install.sh` для полной установки.
- Один основной `goshacrash.sh` со всей логикой управления и маршрутизации.
- Автоматический поиск USB и Download Master без привязки к метке накопителя.
- Восстановление `/opt` и установка пакетов через доступный `ipkg/opkg`.
- Mihomo ARMv5 + gVisor и Zashboard скачиваются с GitHub.
- На legacy обновляется только Zashboard.
- Команда `goshacrash` работает из любого каталога.
- Добавлены системные, установочные, загрузочные и Mihomo-логи.
- Добавлен откат к последнему рабочему конфигу.
